Kit pentru ora de lectură

Rezumatul pentru profesor, planul unei întâlniri de 50 de minute, întrebări pe trei niveluri, o activitate creativă și legătura cu programa. Tot aici: scrisoarea Detectivului Licurici și dosarul de caz pentru elevi. Profesorii le văd în cont și le pot tipări sau salva ca PDF.

ciornă Kitul

Rând gol = paragraf nou · „## ” la început = subtitlu · „- ” = listă · „1. ” = pași numerotați · **text** = îngroșat.

2. Planul întâlnirii 0 / 50 min
3.1 Întrebări · Nivelul 1: La vedere (înțelegere)

Ce scrie în text: fapte, personaje, ordinea întâmplărilor.

3.2 Întrebări · Nivelul 2: Printre rânduri (interpretare)

De ce se întâmplă lucrurile: motive, sentimente, legături.

3.3 Întrebări · Nivelul 3: Concluzia detectivului (reflecție)

Ce cred elevii: păreri argumentate, legături cu viața lor.

4. Activitate creativă

Rând gol = paragraf nou · „## ” la început = subtitlu · „- ” = listă · „1. ” = pași numerotați · **text** = îngroșat.

5. Legătura cu programa școlară

Câte un subtitlu „## ” pentru fiecare clasă, apoi competențele ca listă, cu codul îngroșat. Rând gol = paragraf nou · „## ” la început = subtitlu · „- ” = listă · „1. ” = pași numerotați · **text** = îngroșat.

6. Scrisoarea Detectivului Licurici (o pagină pentru elevi, citită în prima oră)

Antetul, data și semnătura se pun automat. Un paragraf care începe cu „P.S.” apare după semnătură. Rând gol = paragraf nou · „## ” la început = subtitlu · „- ” = listă · „1. ” = pași numerotați · **text** = îngroșat.

Apare pe coperta dosarului și în raportul detectivului.

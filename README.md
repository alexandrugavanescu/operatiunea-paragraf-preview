# Operațiunea paragraf: prezentare și demonstrație

Pagina de prezentare a platformei clubului de lectură „Operațiunea paragraf” al Editurii Paralela 45 și o demonstrație statică a platformei, cu date de test, văzută ca vizitator, ca profesor și ca editură. Formularele din demonstrație nu trimit nimic.

Se publică prin GitHub Pages: Settings → Pages → Deploy from a branch → `main`, folderul `/ (root)`.

Grafica, logourile, copertele și textele cărților aparțin Editurii Paralela 45 și nu pot fi refolosite fără acordul editurii.
